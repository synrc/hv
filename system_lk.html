System Plane (LK)

The Little Kernel microkernel created by Travis Geiselbrecht — powering Android bootloaders, Google Zircon, and real-time embedded environments.

Little Kernel (LK) Environment

The LK System Plane provides an ultra-lightweight, modular microkernel runtime designed by Travis Geiselbrecht. Derived from a rich OS engineering lineage—spanning BeOS at Be, Inc., NewOS (the kernel foundation for Haiku OS), BeFS, Danger Hiptop, and WebOS—LK serves as the core bootloader kernel for Google Android platforms and evolved directly into Google Zircon (Fuchsia OS core kernel).

LITTLE KERNEL & TRAVIS GEISELBRECHT

Minimalist C microkernel providing preemptive multithreading, event objects, fast IPC, mutexes, and high-resolution timer queues.

BEOS, NEWOS & HAIKU LEGACY

Building on NewOS architecture and BeOS multithreading concepts, LK maintains a clean zero-dependency design with instant cold-boot times.

ANDROID & GOOGLE ZIRCON CORE

Ubiquitous Android bootloader runtime (Qualcomm LK) that served as the direct precursor to Google's Zircon capability microkernel in Fuchsia.

FASTBOOT & CONSOLE SHELL

Integrated interactive debug console, fastboot protocol handler, devicetree parsing, and modular BSP target support.
